## 3. a2a-go v2.6.0 速查

### 3.1 JSON 形状(`a2a/core.go`)

- `Task{id, contextId, status, artifacts?, history?, metadata?}`(`core.go:342-361`),**无 `kind`**(1.0 线协)。`contextId` 无 omitempty,SDK 注释"Required to be non empty"。
- `TaskStatus{state, message?, timestamp?}`,`timestamp` 为 `*time.Time`(RFC 3339)。
- `TaskState` 字符串:`TASK_STATE_SUBMITTED|WORKING|INPUT_REQUIRED|AUTH_REQUIRED|COMPLETED|FAILED|CANCELED|REJECTED`,零值编码为 `TASK_STATE_UNSPECIFIED`(`core.go:280-328`)。`Terminal()` = completed/canceled/failed/rejected(`:332`)。
- **陷阱**:`TaskState.UnmarshalJSON` 不校验取值(`core.go:317-328`)。`{"state":"completed"}` 反序列化**不报错**,得到 `TaskState("completed")`,`Terminal()==false` [实测]。契约测试必须比较常量,不能只看"能解析"。
- `Message{messageId, contextId?, extensions?, metadata?, parts, referenceTaskIds?, role, taskId?}`;`role` 为 `ROLE_USER|ROLE_AGENT`(`core.go:152-190,200-228`)。
- `Part` 扁平联合(`core.go:584-756`):恰好一个 `text | raw(base64) | data(任意 JSON) | url`,加 `filename? mediaType? metadata?`。解码时零个或多个内容字段报错;`url:""` 视为无;`data:null` 解不出(n==0)。
- `Artifact{artifactId, name?, description?, extensions?, metadata?, parts}`。
- 事件:`TaskStatusUpdateEvent{contextId, status, taskId, metadata?}`(**1.0 无 `final`**,客户端以终态判结束);`TaskArtifactUpdateEvent{append?, artifact, contextId, lastChunk?, taskId, metadata?}`。
- `StreamResponse` 包装(`core.go:88-150`):`{"task"|"message"|"statusUpdate"|"artifactUpdate": …}` 恰好一个。**JSON-RPC 与 REST 的 SendMessage 结果也是这个包装**(`jsonrpc.go:107-111`、`rest.go:117`),GetTask/CancelTask 返回裸 Task。
- `ListTasksResponse{tasks, totalSize, pageSize, nextPageToken}` 四个字段都无 omitempty(`core.go:868-881`)。
- 请求:`SendMessageRequest{tenant?, configuration?{acceptedOutputModes, returnImmediately, historyLength, taskPushNotificationConfig}, message, metadata?}`;`ListTasksRequest{tenant, contextId, status, pageSize, pageToken, historyLength, statusTimestampAfter, includeArtifacts}`;`GetTaskRequest{tenant, id, historyLength}`;`CancelTaskRequest{tenant, id, metadata}`;`SubscribeToTaskRequest{tenant, id}`。

### 3.2 服务端(`a2asrv`)

- 自实现 `RequestHandler` 直接交给两个构造函数即可,**不需要** `NewHandler`/`AgentExecutor`/`taskstore`。两个 handler 在调用前都已 `NewCallContext(ctx, NewServiceParams(req.Header))`(`jsonrpc.go:50`、`rest.go:64`),所以处理器里 `a2asrv.CallContextFrom(ctx)` 可用,`cc.ServiceParams().Get("A2A-Version")`、`cc.Extensions().RequestedURIs()`(直接返回头的原始值列表,不拆逗号,`extensions.go:64-70`)、`cc.Extensions().Activate(&ext)` 可用。`cc.Method()` 只有经 `InterceptedHandler` 才有值。
- `NewTenantRESTHandler("/a2a/v1/agents/{*}/rest", h)`:模板捕获一段作为 tenant、剥掉前缀后交给 REST mux,并 `fillTenant` 覆盖请求体里的 `tenant`(`rest.go:76-98,503-507`)[实测]。JSON-RPC 没有路径 tenant,AID 要由我们自己的中间件放进 ctx。
- JSON-RPC 方法名:`SendMessage SendStreamingMessage GetTask ListTasks CancelTask SubscribeToTask GetTaskPushNotificationConfig CreateTaskPushNotificationConfig ListTaskPushNotificationConfigs DeleteTaskPushNotificationConfig GetExtendedAgentCard`(`internal/jsonrpc/jsonrpc.go:38-48`)。只查 `POST`,不查 Content-Type(`jsonrpc.go:53`),请求体无上限。
- REST 路径(相对 `…/rest`):`POST /message:send`、`POST /message:stream`、`GET /tasks`、`GET /tasks/{id}`、`GET|POST /tasks/{id}:subscribe`、`POST /tasks/{id}:cancel`、推送 4 条、`GET /extendedAgentCard`(`internal/rest/rest.go:59-120`)。ListTasks 查询参数 `contextId status pageSize pageToken historyLength statusTimestampAfter(RFC3339) includeArtifacts`。
- SSE:`sse.NewWriter(rw)` 要求 `rw.(http.Flusher)`,否则整个流式请求失败(`internal/sse/sse.go:49-55`)。头在处理器开始前就写出(`WriteHeaders`)。流式错误以一条 data 事件(JSON-RPC error 或 REST 错误体)写出。流的迭代器必须尊重 `ctx.Done()`。
- `InterceptedHandler{Handler, Interceptors, Logger}` 可选包一层(日志/拦截器);它的 `capabilities` 未导出,必需扩展检查用不上——本项目不需要(x402 `required` 强制 false)。
- 卡片 handler `NewAgentCardHandler` 会回显任意 Origin 并带 `Allow-Credentials`(`agentcard.go:174-183`),**不要用**,代理卡片自己写字节。

### 3.4 客户端(联调用)

- `a2aclient.NewFromCard(ctx, card, a2aclient.WithCallInterceptors(&a2aclient.AuthInterceptor{Service: creds}), a2aclient.WithConfig(a2aclient.Config{PreferredTransports: …}))`。
- `AuthInterceptor.Before` 只在卡片同时有 `SecurityRequirements` 与 `SecuritySchemes`,**且 ctx 带 `a2aclient.AttachSessionID(ctx, sid)`** 时注入 `Authorization: Bearer <cred>`(`a2aclient/auth.go:56-95`)。`creds := a2aclient.NewInMemoryCredentialsStore(); creds.Set(sid, "anetLocal", token)`。缺 SessionID 时静默不带头 → 401。
- 卡片:`agentcard.DefaultResolver.Resolve(ctx, url, agentcard.WithRequestHeader("Authorization","Bearer "+tok))`。**base URL 有非根路径时不追加 well-known,直接 GET 该 URL**(`agentcard/resolver.go:87-148`)。所以 a2a-go 客户端必须传完整的 `…/agents/<aid>/.well-known/agent-card.json`;按 Hermes 配置里的 `http://<a2a_addr>/a2a/v1/agents/<aid>` 解析会 404(建议加别名路由,§7.4)。解析器接受 `file://`(不要把对端给的 URL 交给它)。
- 默认 HTTP 客户端 `Timeout: 3*time.Minute`(`transport.go:26`),会切断长阻塞与 SSE;联调传无 Timeout 的 `http.Client`(`WithJSONRPCTransport/WithRESTTransport`)。客户端 SSE 单行上限 10 MiB(`internal/sse/sse.go:39,99`)。
- 客户端每次请求带 `A2A-Version: 1.0`(`client.go:270`)。

## 4. `internal/a2ashape` 类型草案

原则:无 build tag,只用标准库,**不 import a2a-go**,也不 import `interactions`(投影函数放 daemon);JSON 与 a2a-go 类型双向往返。下列代码在 scratchpad 副本中与 a2a-go v2.6.0 往返通过 [实测]:a2ashape→JSON→`a2a.Task`→JSON→a2ashape→JSON 字节相同(单键 data;多键 data 经 a2a-go 会按键排序,测试应做语义比较);`a2a.StreamResponse` 能解出 `*a2a.TaskStatusUpdateEvent`;`go list -deps ./internal/a2ashape | grep -c a2aproject` = 0。

```go
// Package a2ashape is the A2A 1.0 JSON projection of anet tasks (A2A-DESIGN §11.1, §12).
// It must not import a2a-go (SI-8); module/a2a converts to SDK types by a JSON round trip.
package a2ashape

type TaskState string

const (
	StateSubmitted     TaskState = "TASK_STATE_SUBMITTED"
	StateWorking       TaskState = "TASK_STATE_WORKING"
	StateInputRequired TaskState = "TASK_STATE_INPUT_REQUIRED"
	StateAuthRequired  TaskState = "TASK_STATE_AUTH_REQUIRED"
	StateCompleted     TaskState = "TASK_STATE_COMPLETED"
	StateFailed        TaskState = "TASK_STATE_FAILED"
	StateCanceled      TaskState = "TASK_STATE_CANCELED"
	StateRejected      TaskState = "TASK_STATE_REJECTED"
)
func (s TaskState) Terminal() bool    { /* completed failed canceled rejected */ }
func (s TaskState) Interrupted() bool { return s == StateInputRequired || s == StateAuthRequired }
// FromAnet/Anet: "input-required" <-> StateInputRequired 等,纯字符串映射,不 import interactions。
func FromAnet(s string) TaskState
func (s TaskState) Anet() string

type Role string
const (RoleUser Role = "ROLE_USER"; RoleAgent Role = "ROLE_AGENT")

// Part: exactly one of Text/Raw/Data/URL.
type Part struct {
	Text      *string         `json:"text,omitempty"` // 指针:空串文本也要能表达
	Raw       []byte          `json:"raw,omitzero"`   // omitzero:nil 省略,[]byte{} 输出 "raw":""(空文件)
	Data      json.RawMessage `json:"data,omitempty"` // 保留原字节,避免大整数被 float64 化
	URL       string          `json:"url,omitempty"`  // 只出现在输出里;输入里一律 InvalidParams
	Filename  string          `json:"filename,omitempty"`
	MediaType string          `json:"mediaType,omitempty"`
	Metadata  map[string]any  `json:"metadata,omitempty"`
}
func TextPart(s string) Part
func DataPart(v any) Part                      // json.Marshal(v),MediaType "application/json"
func FilePart(name, mime string, b []byte) Part // b==nil 时置 []byte{}
func (p Part) Kind() (string, error)            // "text"|"raw"|"data"|"url";0 个或多个 → 错

type Message struct {
	MessageID        string         `json:"messageId"`

	TaskID           string         `json:"taskId,omitempty"`

}

	State     TaskState  `json:"state"`
	Message   *Message   `json:"message,omitempty"`
	Timestamp *time.Time `json:"timestamp,omitempty"` // time.UnixMilli(ix.StateAt).UTC()
}
type Artifact struct {
	ArtifactID  string         `json:"artifactId"`
	Name        string         `json:"name,omitempty"`
	Description string         `json:"description,omitempty"`
	Parts       []Part         `json:"parts"`
	Metadata    map[string]any `json:"metadata,omitempty"`
	Extensions  []string       `json:"extensions,omitempty"`
}
type Task struct {
	ID        string         `json:"id"`
	ContextID string         `json:"contextId"`
	Status    TaskStatus     `json:"status"`
	Artifacts []Artifact     `json:"artifacts,omitempty"`
	History   []Message      `json:"history,omitempty"`
	Metadata  map[string]any `json:"metadata,omitempty"`
}
type TaskStatusUpdateEvent struct {
	TaskID    string         `json:"taskId"`

type TaskArtifactUpdateEvent struct {

// TaskEvent is A2A StreamResponse: exactly one field set.
type TaskEvent struct {
	Task           *Task                    `json:"task,omitempty"`
	Message        *Message                 `json:"message,omitempty"`
	StatusUpdate   *TaskStatusUpdateEvent   `json:"statusUpdate,omitempty"`
	ArtifactUpdate *TaskArtifactUpdateEvent `json:"artifactUpdate,omitempty"`
```

### 4.1 从 interactions 投影(放 `internal/daemon/taskview.go`)

签名建议:`func (d *Daemon) projectTask(ix *interactions.Interaction, o projOpts) (a2ashape.Task, error)`,`projOpts{HistoryLen *int; IncludeArtifacts bool; Bytes bool}`。

- `id` = interaction id(`ix_<hex>`);`contextId` = `ix.ContextID`,**为空时(wire 2 之前的行)回填确定值**,如 `"ctx_"+strings.TrimPrefix(id,"ix_")`,不要输出空串。
- `status.state` = `a2ashape.FromAnet(string(ix.State))`;`timestamp` = `state_at`。
- `history`:`d.ix.Messages(id)` 中 `Kind==MsgText && !hasControlMeta(m.Metadata)` 的行,按 seq;`role` 按"发送方是否请求方"定(outbound:自己=user;inbound:对端=user)。`messageId` 取 `metadata["a2a.messageId"]`(客户端给的),否则 `m.MsgID`,再否则 `"m"+seq`。附件在历史里**不带字节**,渲染为 `DataPart({"anet.attachment":{name,mime,size,cid}})`(理由见陷阱 §11-8)。能力任务:请求方首条消息是合成文本 `"invoke capability X args=…"`(`capability.go:208`),投影时改为 `DataPart({"skill":capID,"args":…})`(从 `ix.RequestDoc` 解 `capabilityCall(decodeTaskDoc(...))`,`capability.go:91,601`);提供方把交付物 JSON 也存成了一条 `MsgText`(`capability.go:531`),**能力任务的 history 必须排除它**。`historyLength`:nil=全部(GetTask/Send),0=省略,>0=最后 N 条;ListTasks 缺省建议 0。
- `status.message`:input-required(文本任务)= 提供方最近一条对话消息;working = 最近一条 `anet.state=working` 的提供方消息(若有);failed/rejected = 最近 `MsgStatus` 行的 `Body` + `metadata["anet.reason"]`;付款导致的 input-required 由 C3 填(x402 `payment-required` 消息)。没有内容就省略 `message`,不要输出空 `parts`。
- `artifacts`(GetTask 总是给;ListTasks 仅 `includeArtifacts`):
  - 完成的文本任务:`{artifactId:"anet.reply", parts:[TextPart(最后一条 From=="provider" 的正文)]}`,来源 `transcript.Parse(ix.Result)`(回执覆盖的那份);
  - 能力任务:`{artifactId:"anet.result", parts:[DataPart(交付物 JSON 原字节)]}`;
  - 其后 `{artifactId:"anet.receipt", parts:[DataPart({"receipt":base64(ix.Receipt),"request_cid","result_cid","verified":…})]}`;
  - 再后提供方附件 `{artifactId:"att-"+cid, parts:[FilePart(safeName(name), mime, bytes)]}`——字节有上限(§11-8)。
- `metadata`:`anet.peer_aid`、`anet.request_cid`、`anet.result_cid`、`anet.receipt_verified`(`""`→`"unknown"`)、`anet.state_seq`(数字;供 `/tasks/wait` 与阻塞发送比较,设计未列但无害)、能力任务的 `anet.effect_status`、`anet.reason`/`anet.retry_after_ms`(读 `result_meta`,02 §1.3-2 建议新增该列;否则取最近 `MsgStatus` 的 metadata)、`anet.cancel_requested=true`(推导:outbound、非终态、`pay_state=submitted`、存在本方 `MsgCancel` 行)、C3 的 `x402.*`。
- `anet.effect_status` 取值(SI-6 要求能力任务终态必有):有交付物 → 交付物的 `status`;无交付物时按 02 §11 的建议规则:rejected/failed 无结果 → `UNAVAILABLE`,执行前 canceled → `UNAVAILABLE`,中断 → `UNVERIFIED`(带 `anet.reason=interrupted`)。设计未写这条,须产品负责人确认(见风险)。
- 绝不从 `effect_status`/`receipt_verified` 反推 state:两个字段并存,`UNVERIFIED` 仍是 `TASK_STATE_COMPLETED`(`stateForEffect` 已如此,`capability.go:418-437`)。

### 4.2 输入解析(`parseTaskInput`,放 daemon,两面共用)

```go
	var out T

func (h handler) SendMessage(ctx context.Context, r *a2a.SendMessageRequest) (a2a.SendMessageResult, error) {
	if err := checkTenant(ctx, r.Tenant); err != nil { return nil, err }
	ver, exts, err := serviceParams(ctx, h.supported(peerFrom(ctx))) // 读 CallContext;非 1.x → a2a.ErrVersionNotSupported

	t, err := h.seam.Send(ctx, peerFrom(ctx), req)
	if err != nil { return nil, mapErr(err) }
	out, err := conv[a2a.Task](t)

// GetExtendedAgentCard 返回 a2a.ErrUnsupportedOperation(或 ErrExtendedCardNotConfigured)。

func (h handler) SubscribeToTask(ctx context.Context, r *a2a.SubscribeToTaskRequest) iter.Seq2[a2a.Event, error] {
	return func(yield func(a2a.Event, error) bool) {
		snap, ch, err := h.seam.Watch(ctx, peerFrom(ctx), string(r.ID))
		if err != nil { yield(nil, mapErr(err)); return }
		if snap.Status.State.Terminal() { yield(nil, a2a.NewError(a2a.ErrUnsupportedOperation, "task has ended")); return }
		first, _ := conv[a2a.Task](snap)
		if !yield(&first, nil) { return }           // 规范 §3.1.6:首个事件是 Task
		for {
			select {
			case <-ctx.Done(): return
			case ev, ok := <-ch:
				if !ok { return }
				sr, err := conv[a2a.StreamResponse](ev)
				if err != nil { yield(nil, err); return }
				if !yield(sr.Event, nil) { return }
			}
		}
	}
}

func NewServer(seam module.TaskSeam, token, port string) http.Handler {

	jsonrpc := a2asrv.NewJSONRPCHandler(h, a2asrv.WithTransportKeepAlive(15*time.Second), a2asrv.WithTransportPanicHandler(panicToInternal))
	rest := a2asrv.NewTenantRESTHandler("/a2a/v1/agents/{*}/rest", h, a2asrv.WithTransportKeepAlive(15*time.Second), …)
	mux := http.NewServeMux()
	mux.HandleFunc("GET /a2a/v1/agents", listAgents)
	mux.HandleFunc("GET /a2a/v1/agents/{aid}/.well-known/agent-card.json", serveProxyCard) // 自己写签名字节
	mux.HandleFunc("GET /a2a/v1/agents/{aid}", serveProxyCard)                           // 别名,见 §7.4
	mux.Handle("POST /a2a/v1/agents/{aid}/jsonrpc", jsonrpc)
	mux.Handle("/a2a/v1/agents/{aid}/rest/", rest)
	return chain(mux, hostGuard(port), noOrigin, bearer(token), aidFromPath, contentType, bodyLimit(96<<20), normalizeServiceParams, echoExtensions)
}
```

### 7.3 中间件链(顺序即执行顺序)

1. `hostGuard`:Host 必须是 `127.0.0.1|localhost|[::1]` + 监听端口,否则 421。把 `ctlsec.go:172-199` 的 `loopbackName/allowedHost` 抽到无 tag 小包(如 `internal/loopback`),控制面与本模块共用;模块不要 import `internal/daemon`。
2. `noOrigin`:`Origin` 非空 → 403。
3. `bearer`:`subtle.ConstantTimeCompare(Authorization, "Bearer "+a2aToken)`,失败 401。控制令牌在此处必须失败,A2A 令牌在控制面必须失败(SI-7,两侧各一条测试)。REST 客户端遇到纯文本 401 只报 "server error" [实测],可按绑定写 JSON 错误体(可选)。
4. `aidFromPath`:从 `/a2a/v1/agents/{aid}/…` 取 AID,校验 `[a-z0-9]{1,128}`(与 `a2acard.validAID` 同规则,它未导出),放进 `aidKey`。处理器里请求体的 `tenant` 非空且 ≠ 路径 AID → `ErrInvalidParams`(`checkTenant`)。
5. `contentType`:JSON-RPC 路径只接受 `application/json`(`mime.ParseMediaType`),否则 415(挡 `text/plain` 跨源 POST,0001 S5)。
6. `bodyLimit`:`http.MaxBytesReader(w, r.Body, 96<<20)`。
7. `normalizeServiceParams`:`A2A-Extensions` 与 `X-A2A-Extensions` 的全部值按逗号拆分、去空白、合并,写回 `r.Header["A2A-Extensions"]` 为多值,删 `X-A2A-Extensions`;查询参数 `A2A-Version` 在无头时复制成头。版本判定留给处理器(§3.3)。
8. `echoExtensions`:响应头 `A2A-Extensions: <请求的 ∩ 该 AID 代理卡片声明的>`,在调用 mux **之前**写(流式的头会在处理器开始前发出)。

### 7.4 路由

设计 §11.2 四条全部要 Bearer。建议加一条别名 `GET /a2a/v1/agents/{aid}` → 同一张代理卡片:a2a-go 的解析器对非根路径不追加 well-known(§3.4),Hermes 配置写的就是这个 base URL。代理卡片里的接口:`{url:"http://127.0.0.1:<port>/a2a/v1/agents/<aid>/jsonrpc", protocolBinding:"JSONRPC", protocolVersion:"1.0"}`、`{url:"…/rest", protocolBinding:"HTTP+JSON", protocolVersion:"1.0"}`,**不设 `tenant`**(设了的话 a2a-go REST 客户端会把 tenant 拼进路径,`a2aclient/rest.go:100-101`)。

### 7.5 错误映射(`convert.go`)

`a2ashape.ErrTaskNotFound→a2a.ErrTaskNotFound`、`ErrTaskNotCancelable→a2a.ErrTaskNotCancelable`、`ErrUnsupportedOperation→a2a.ErrUnsupportedOperation`、`ErrInvalidParams→a2a.ErrInvalidParams`、`ErrNoHub`/投递失败→`a2a.ErrInternalError`("delivery failed");`context.DeadlineExceeded` 原样(REST 映射 504)。一律 `a2a.NewError(哨兵, 固定文案)`。

### 7.6 代理卡片(§11.3;卡片层约束见 06 §5)

- 建议由内核构建并签名(`TaskSeam.ProxyCard(ctx, aid, baseURL)`,用 `a2acard.Sign` + `d.self`,kid `did:anet:<本机AID>#<seq>`,无 jku),模块只缓存与写出字节(按 AID 缓存 5 分钟,端口变化即失效)。不要给模块原始 `Sign(preimage)`(`HubSeam/PaymentSeam.Sign` 是裸签名器,`paylink.go:55,139`)。
- 内容:复制远端已验证网络卡片的 `name/description/version/skills/defaultInputModes/defaultOutputModes`;`capabilities{streaming:true, pushNotifications:false, extensions:[anet-origin/v1{params:{originCard:<远端原字节 base64url>, originVerification}}, 远端声明 x402 或 anet-pricing 时加 x402{params:{signer:"anet-daemon",clientPayload:false}} 且**省略 `required`**,远端的 anet-pricing 原样带过]}`;`securitySchemes:{"anetLocal":{"httpAuthSecurityScheme":{"scheme":"Bearer"}}}`、`securityRequirements:[{"schemes":{"anetLocal":{}}}]`(a2a-python 会把空 `{}` 级联删掉,06 §5 建议 `AllowEmptyScopes` 选项)。
- 远端无网络卡片(**当前一律如此**,hub 无注册表、daemon 不发 A2A 卡):`name` 用 hub `/agents/{aid}` 的名字或 AID,description 如实写"未验证",skills 一个 `{"id":"chat","name":"chat","description":"…","tags":["chat"]}`,`originVerification:"UNVERIFIED"`。不要把 hub 的 `caps` 写成 skills(hub 陈述,未签名)。
- 必须用发布形(0012/06 §3.1):任何非 optional 字段不输出默认值(空 description、空数组、`required:false`、空 `tenant`)。

### 7.7 端口与令牌

- `a2a_addr.txt`、`a2a_token.txt`(0600)放 `StateDir("a2a")`。令牌:24 字节随机 hex,首次启动生成,永不写日志;轮换 = 删文件重启 + `anet agents wire --refresh`(D2)。
- 端口:首次从固定基址扫描(建议 43811 起 2000 个,避开控制面 `39811–41810`,`identities.go:32`),选中后写文件;之后每次先绑文件里的端口,`EADDRINUSE` 时重扫、重写、记日志(同 `listenControl`,`control_api.go:248-277`)。"跳过其他身份占用的端口"需要枚举全部身份目录:把 `AnetHome()` 与 `ListIdentities` 的目录遍历(`identities.go:48-57,208-238`)抽到无 tag 小包,模块读各身份的 `modules/a2a/a2a_addr.txt`。非回环地址拒绝。

### 7.8 生命周期陷阱

- **`Daemon.Close()` 不调用 `stopModules`**(`daemon.go:327-357`;`stopModules` 只在 `validate` 失败时调用,`daemon.go:221`)。模块唯一可靠的停机信号是 `Start(ctx, …)` 的 `ctx`(即 daemon 的 `d.ctx`,`Close` 先 `d.cancel()`)。做法:`srv := &http.Server{Handler, ReadHeaderTimeout: 5*time.Second, BaseContext: func(net.Listener) context.Context { return ctx }}`,`go srv.Serve(ln)`,`go func(){ <-ctx.Done(); srv.Shutdown(3s) }()`;`BaseContext` 让所有请求(含 SSE、阻塞发送)随 daemon 关闭而结束,否则 `Shutdown` 会等 SSE 到超时。`Stop` 也要能关(validate 失败路径)。
- `Start` 在 `daemon.New` 里调用(`daemon.go:213`),先于控制面;`cmd/anet` 的测试 `console_cli_test.go:29` 会调 `daemon.New`,链接了 `module/a2a` 后会真的绑端口——测试需设 `ANET_HOME` 临时目录。
- 不设 `WriteTimeout`(SSE、阻塞发送);`KeepAlive` 15s。

### 7.9 付款消息(§8.7,依赖 C3)

`SendMessage` 带 taskId 且 `metadata["x402.payment.status"]=="payment-submitted"` → `seam.Pay(submit, metadata["anet.payment.accept"])`;`payment-rejected` → `Pay(reject)`;带 `x402.payment.payload` → 任务 `status.message` 给 `payment-failed/SETTLEMENT_FAILED/anet.reason=client_payload_unsupported`(不转发)。客户端是否激活 x402 从 `TaskSend.Extensions` 判断(§8.7 末条)。

### 7.10 §11.6 后端(可选,最后做)

`Start` 里若有 `accept_untrusted:true` 的后端先 `h.DeclareUntrustedBackend()`(已有接缝,`inbound.go:552`);转发只取 `trust_file` 对端的已接受文本任务——这需要 TaskSeam 之外的入站接缝(设计未给),做时再定。

## 11. 陷阱汇总

1. `a2a.TaskState` 不校验取值,小写状态能"成功"反序列化(§3.1)。契约测试比常量。
2. `Parts`、`TaskPage.Tasks` 为 nil 时编码成 `null`;构造时给空切片。`contextId` 不能为空(旧行回填)。
3. JSON-RPC/REST 的 SendMessage 结果包在 `{"task":…}` 里,GetTask 不包;控制面 `/tasks/send` 返回裸 Task。Hermes 的 `_reply_text_from_result` 移植版要按 A2A 1.0 形状写(设计 §17 契约项)。
4. 错误消息原样上线(§3.3),必须 `a2a.NewError(哨兵, 固定文案)`。
5. 请求方 `DelegateIn`/`SendMessageOpts` 先写本地再 `relaySend`,不入队(02 §14-4):发送失败时本地已有 `submitted` 行,客户端重试得第二个 ix。A2A `SendMessage` 需要决定:经 `queueSend` 入队(复用信封字节,返回 submitted 任务),或失败即把本地行置 failed(`failUndelivered`,wt/tasksd 的做法)并回错。
6. `hasControlMeta` 把 `anet.state` 当控制键(`delegation.go:421-435`):带 `anet.state=working` 的进度消息不进 history、不进回执对话记录。`/tasks/reply state=completed` 若先发一条普通文本再 `CompleteTask`,请求方会先进 `input-required`(`stateOnMessage`,`delegation.go:377-403`),阻塞的 A2A 客户端在此返回,拿不到 `anet.reply`。建议:最终答复只本地入库(不单独发 `anet.message/1`),由 `CompleteTask` 的对话记录带给请求方,请求方从 transcript 取 `anet.reply`。需设计确认。
7. A2A 面没有"请求完成"(`end_request`)的操作,文本任务会一直停在 `input-required`。建议约定 `SendMessage{taskId, metadata:{"anet.end_request":true}, parts:[]}` → `RequestEnd`,写入设计与 §19 绑定草案。
8. 大附件:a2a-go 客户端 SSE 单行 10 MiB(`internal/sse/sse.go:39`),base64 后约 7.5 MiB 原始数据就会使流失败;history 与 ListTasks 带字节会把 MCP/客户端上下文撑爆。建议:流式事件与 history 只给附件元数据 DataPart;GetTask 的产物内联字节设总上限(如 8 MiB),超出给元数据并提示 `anet pull`。设计未写,需确认。
9. `Daemon.Close` 不停模块(§7.8)。
10. 模块拿不到 `internal/daemon` 的 `allowedHost`、`AnetHome`、`ListIdentities`,需抽公共小包;不要让模块 import `internal/daemon`。
11. 事件总线乱序/重复(02 §7-1)与慢订阅者被踢(需重订)。
12. 代理卡片签名需要内核接缝(设计 §11.1 的 TaskSeam 没有),不要用 `HubSeam.Sign` 这类裸签名器。
13. a2a-go 解析器对非根 base URL 不追加 well-known;默认 3 分钟超时;`AuthInterceptor` 需要 SessionID(§3.4)。
14. `A2A-Version` 缺省按 1.0 是对规范"缺省按 0.3"的偏离(§2 已定,§21-12 写明);a2a-x402 v0.2 的示例是 0.3 线协(`"kind":"task"`、`"state":"input-required"`、`X-A2A-Extensions`),0.3 客户端连不上(兼容层 `a2acompat/a2av0` 会拉入 grpc,§0001 表 2.1)。
15. 历史消息 `messageId`:客户端给的存 `metadata["a2a.messageId"]`,本地 `msg_id` 是 daemon 铸造的;投影优先用客户端的,两侧一致性另见 02 §13-C5-3(首条消息与 StatusMsg 在线协上无 msg_id)。
