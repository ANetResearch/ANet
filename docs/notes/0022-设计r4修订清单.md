## 2. 决定文字与实现不一致、按实现写入的地方(请确认)

1. **Q2**(§4.3):`0017` 的文字是"无结果的 rejected/failed → UNAVAILABLE;执行前 canceled → UNAVAILABLE"。决定本身是"追认 wp/a2ashape 的规则",而该规则的实现(`internal/a2ashape` `effectStatus`)是:无交付物时 rejected → UNAVAILABLE;结果元数据写明效果的照写(`undeliverable` → UNAVAILABLE、`interrupted` → UNVERIFIED);canceled 与其余未写明的(含 failed)→ UNVERIFIED。r4 按实现写,理由是请求方看不到对端是否已开始执行。若要按 `0017` 的文字改实现,需另开小修。
2. **Q3**(§4.1):决定写"新列 `cancel_requested`";实现以推导满足同一语义(`pay_state ∈ {submitted, completed}`、非终态、存在本方 cancel),不加列(`wp/wire 1591718` 明说)。r4 按实现写。
