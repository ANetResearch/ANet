# Reason codes of anet: the register of every code ever published.
#
# A reason code is a stable public interface. Scripts match on the code, never
# on the sentence, so the meaning of a code never changes, a code is never
# renamed, and a code that has been published is never used again for another
# meaning. This file is edited by hand and deliberately; there is no
# regeneration. internal/a2ashape/codes_registry_test.go holds it against the
# reason table in reasons.go, and docs/_tools/gen_reason_codes.py renders it
# into docs/reference/reason-codes.rst.
#
# One line per code, sorted by code, fields separated by a tab:
#
#     code   since   status   [retired   [replacement]]
#
#   code         the Code of a row of the reason table (not a dotted sentence
#                key, not an "x402:" row).
#   since        the first anet version that emitted the code: 0.3.0, 0.3.1,
#                0.3.2 or 0.3.3, in the form major.minor.patch.
#   status       active: the table has a row for the code.
#                retired: the table has no row for it any more. The line
#                stays, so the name is never reused.
#   retired      for a retired code, the version that removed the row.
#   replacement  for a retired code, optionally the code that took its place.
#
# To add a code, append its line with the version being prepared. To retire
# one, change its status, add the retiring version, and remove the row from
# the table in the same commit. See docs/contributing.rst.
